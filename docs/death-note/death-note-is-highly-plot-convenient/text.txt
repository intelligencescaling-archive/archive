**Note:** There's a difference between something that happens DUE to plot(induced/story direction) and something that happens BECAUSE OF plot (hole/armor/convenience/contrivance).

Due:- event logically and naturally follows within the established context (I get up because I want to stand. There is a lot of space so I am able to stand up freely)

Because of:- event *can* logically follow but doesn't naturally follow within the established context (I stand up because I want to. But there is no place to stand so I technically am not able to stand within this place. Nevertheless, I will stand because I want to)

Authors do not willingly ruin their work by inserting what they want into a story. Thats a strong misconception. They only include it if they see no logical alternatives or aren't good enough to write the scene how they'd like.

When that happens they can either scrap it or go through with what they have already which can either be good or detrimental for the story itself.
