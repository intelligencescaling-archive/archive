Let's firstly know the given values.

L had to review 10,000 hours of footage and audio recordings in 48 hours. He sped up the recordings to do so.
We get this number if we consider only 400 monitors. Now if we consider standard FPS it's about 30 FPS on which each recording is played usually, we get following given values:

Given,
Footage to be reviewed:10,000 hours=36000000 seconds
Time given:48 hours=172800
FPS:30 FPS
To know at what rate L processed frames,we would use following formula:

Standard FPS×Footage to be covered/Time given

Calculations:

30×36000000/172800=6,250FPS

So L processed 6,250 raw frames per second.
As L was psychoanalysing and noticing small details of each footage,so we can interpret it to get our values in operation per second.
