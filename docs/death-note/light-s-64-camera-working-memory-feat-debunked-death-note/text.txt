Light's 64 camera working memory feat DEBUNKED

Some death note fans use the 64 cameras feat to buff Light's working memory to 64 objects.

Some go a step further and say Light needs to keep the coordinates and direction of all the cameras in mind, thus buffing it to 256 objects.

They are both mistaken.

First of all, humans are efficient thinkers, we don't do stupid things like memorizing coordinates in all the axes of space separately when memorizing locations of objects. If I tell you that my pen is on the fridge, you don't need to memorize the 3 coordinates of the pen, you only need to think of the pen relative to the fridge (above it). If I tell you to memorize my face, you don't need to memorize every single eyebrow and hair follicle and atom that composes my face, nor every angle and position and tilt. When humans are built to memorize certain things, there is no need to overcomplicate and pretend it's more complex than it actually is. Bringing up axes in space overrates the feat because the coordinates have got nothing to do with the actual cognitive requirement.

Secondly, humans are built to memorize locations easily, which is what the entire concept of "memory palaces" is premised on. Especially locations within familiar space (Light's own bedroom is familiar to him). Light doesn't even need to think of the type of object, since all of the 64 objects are security cameras. This is far easier than what real life memory champions do which involves memorizing different objects, memorizing the sequence they are given in, memorizing them in abstract without location, and having a far narrower time constraint (such as 1 object per second). Light's feat is far far below what many real life humans have actually done at their cognitive peak, so DN fans using this feat to place Light above all real life humans in cognition (or working memory) is foolish. Even average humans can achieve the same thing with enough training, although I'd say Light is far above average since he *probably* didn't do any memory training and used only his raw memory. If you want to surpass Light's feat yourself, I recommend looking into memory palaces. It's not that difficult.

Thirdly, the entire feat is **short term memory**. Not working memory. People keep equalizing them which is why they make the mistake of thinking monitor hax heavily upscales L's working memory. L's working memory in the manga is actually nothing special. Even my own working memory is above L's.

What Light did here was memorize the positions of the cameras. Short term memory -> long term memory. Even the manga shows that Light had the positions memorized by the next day (long term memory). Short term memory and working memory are obviously closely related, but they are not the same. Where is the working memory requirement in this feat? Do you people not understand how working memory works?

**Light's actually valid CPI feat**

Light observes the face and name of the criminal, memorizing both (timescale is ambiguous). Writes a letter of the name at a time, after which he takes a potato chip and eats it. When the final letter is written, Light needs to bring the face of the criminal back into his mind. The full name of one of the criminals shown had 6 Japanese letters. Light also needs to keep the positioning accurate, both vertically and horizontally. This will also need to be done quickly (switching between pen and potato chip). On the right side, Light Yagami is simultaneously solving what appears to be high school calculus questions.

This feat is narratively valid for working memory, since there wasn't any evidence of significant breaks between the left and right processes. It can't really be quantified, but it's still an impressive feat far above average humans.

3 character first name + 3 character last name + letter he is up to + position of the letter he previously wrote + face + whatever is required for the mathematics questions being solved on the right side (ambiguous but usually mathematics questions require high working memory to solve). Several of these objects also change continuously which makes it part of working memory and not just short term memory. Also since the objects are actually abstract and not just locations in a familiar space, it's far more valid for working memory compared to the 64 camera feat.

However, you need to keep in mind that 3 character name does not necessarily mean 3 objects in working memory. For common names, they may be part of long term memory and the full name can count as one object. For example if I tell you to memorize the name "Alexander" or "Hitler", both of these require a working memory of 1 object for you to keep the name in mind, not 1 object per character. Even this is an oversimplification since it can potentially take less working memory than 1 distinct abstract object depending on how familiar the name is.

**Conclusion**

The 64 camera feat is a memorization feat. It has almost nothing to do with working memory.

The potato chip multitasking feat is what you call actual working memory. It is impressive given Light's age.
