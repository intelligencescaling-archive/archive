Moving on to code feat. Now let’s talk about the real scope of code feat.

OK so, one thing to notice is that they have been using this language ever since Dazai got jailed. That’s because they had to keep their conversations a secret and the guard guy said just before this panel “What have these guys been talking about this whole time?”. Therefore “two of them memorized their past conversations” refers to the time they spent together an unknown amount of years ago. Let’s get into the magnitude of the feat. Requirements for the feat:

MEMORY / CPI

* Perfect memory: They have to be able to recall everything perfectly to be able to access those memories in the first place, any missing memory could cause errors.
   *  Speed of memory access: They would need to recall vast amounts of information instantly. This includes not just recalling words but entire conversations, concepts, and associations that have been built over time. Real-time recall at this level would likely require near-instantaneous memory access speeds, comparable to how a high-speed computer retrieves data.
   * Instant decoding: As soon as one speaks, the other must be able to instantly decode the message, understanding what is being said without any delay

REASONING

* Shared knowledge base: They must have a deep understanding of each other’s thought processes, including knowledge of literature, philosophy, history, and other shared subjects that they can reference. Their mind reading plays a huge part here.
   * Logical reasoning via interpreting multiple possibilities: When they receive a coded message, there might be multiple potential meanings based on their past conversations or shared knowledge. Logical reasoning allows them to evaluate these possibilities and select the most likely or appropriate interpretation. For example, if a code could refer to either "escape" or "meeting," logical reasoning helps them determine which fits the context of their conversation.
   * Pattern recognition: Since they’re communicating using a custom, improvised code language, each message is based on patterns they’ve previously established or understood from past interactions. Recognizing these patterns helps them decode the message quickly. For example, if certain sounds or words consistently correspond to specific meanings, recognizing these patterns allows them to understand the new code instantly.
   * Associative thinking: Self explanatory.
