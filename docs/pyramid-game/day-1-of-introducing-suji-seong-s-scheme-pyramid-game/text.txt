 **What Pyramid Game is:**

Being held in the "Happy Class", Pyramid Game is a voting-based activity with the frequency of once a month each Monday to decide each person's social hierarchy, divided from class A to F. Each person was given 5 votes to use it on 5 other person, the voter is prohibited to vote for themselves or use more than 1 vote on the same person.
