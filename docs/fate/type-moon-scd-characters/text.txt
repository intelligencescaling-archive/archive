- Phrases that you might not be familiar with :

SCD = Smart Characters Debates, representing Intelligence Scaling Communities just like how Powerscaling is called WIS which means -Who is stronger-.

Comp = Composite, meaning every official version of the character in every single adaptation.

Example :
Comp Gilgamesh = [Fate/Zero - Fate/Stay Night - Fate/Grand Order - etc…]

A character that doesn’t have Comp in them means the character has only shown their feats in one media type of Type-Moon like Qin Shi Huang who only shows up in Fate/Grand Order Game and has no feats anywhere else.
