Wall Cipher Feat

D3rlord3 notices a very large text engraved into the wall and recognizes it immediately as a cipher and with a pen, paper and a candy cane is able to solve it in 25 minutes (obviously an intentional choice by Wifies to make it 25 and not 17 like with D3rlord3 cuz 25th of December), despite the fact that it is very long, a bit over 100 characters and also it involves cipher stacking, a technique explained in the video. Keep in mind, D3rlord3 is able to solve it despite the fact that he cannot infer the yellow king theme (especially since the world is Christmas-y and there is literally no King in Yellow theme so far at all) and well is using pen and paper. The creator acknowledges that it does not belong to any cipher family he has seen before. So yea, D3rlord3 literally had to find the key himself in 25 minutes without even knowing of any theme, he still just somehow did anyway.

Keep in mind, D3rlord3 had to, in 25 minutes, using just pen and paper (and candy cane), decode this entire 100+ character cipher that he had to find the key of first. He noticed it used cipher stacking and he managed to find the key (which should be CIPPSA, given how he tells us what the plaintext of the code is afterwards, which confirms it is the same as the code from the regular D3rlord3 ARG and it 100% confirms that is the code of the D3rlord3 ARG) in a relatively short amount of time.

Cipher stacking combines two coding methods one on top of the other, which makes a message indecipherable as when you decode the first message you still get a coded message that you then have to decode next, so it means more work, especially for longer texts like these.

He then notices there is a combination lock and tries flipping the levers, of course it does not work on the first try, but he just resorts to a more common sense solution and just breaks the door with his pickaxe to get through.
