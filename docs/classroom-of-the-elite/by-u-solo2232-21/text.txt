Y1V3 - Uninhabited Island Exam
Exam Rules: This is the first special exam that the students will take. It takes place on a deserted island and allows classes to earn class points. Each class starts the exam with 300 points, which they can use to make the necessary purchases to survive on the island. The remaining points at the end of the exam will be added to their class points, so it is essential to save as much as possible. Each class must appoint a leader and will then receive an electronic card with the leader's name written on it.
There are different ways to gain and lose points:
1. Expenses for basic necessities: Food, water, etc. These do not cost too much, approximately 5 points maximum.
2. A student's withdrawal: Losing a student costs the class 30 points.
3. School roll calls: The school will make announcements requiring everyone to gather at 8 AM and 8 PM. If a student fails to show up, the class loses 5 points per absent student.
4. Spots: There are locations that classes can conquer using their leader's card. A spot conquered by a class expires after 8 hours. After that period, it must be conquered again. Each spot earns 1 point.
5. Identifying the opposing class leader: If a class manages to guess and write down the name of the actual leader of a competing class at the end of the exam, it earns 50 points per leader.
6. Incorrectly identifying a leader: If a class writes down the wrong leader's name at the end of the exam, it loses 50 points per incorrect name.
7. Changing leaders: It is possible to change leaders during the exam, but there must be a valid reason.
Class A starts with 270 points due to Sakayanagi's handicap, which prevents her from participating.

Scout

Only one student can hold this position. If they are eliminated, a guard can replace them.

(Baseline)
They must also deduce that Ayanokoji could have anticipated Ryuuen's attack with certainty.

(2nd Layer)

(4th Layer)

Strategy Shielding

1. By volunteering to take responsibility for his class's expulsion in the event of defeat, he gained complete control over his own class's actions, as well as influence over Ichinose's class.
2. Through his various unpredictable tactics, he left the other classes with no choice but to act exactly as he wanted, from beginning to end.
Strategy Adaptability
1. Nothing particularly noteworthy, since he did not encounter any unexpected situations because he had prepared for every possible outcome.
