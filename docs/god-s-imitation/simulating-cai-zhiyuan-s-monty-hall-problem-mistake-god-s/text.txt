Simulating Cai Zhiyuan's Monty Hall Problem mistake

I've already debunked Cai Zhiyuan's mistake of assuming the Monty Hall problem where it doesn't apply.

The conclusion is that one of the following applies:

Possibility 1: The game has nothing to do with the Monty Hall problem. It is entirely psychological. Whether the host does one thing or another thing to kill the contestant vs spare him is up to his whims because the bullets aren't randomly distributed. The criminal isn't in a Monty Hall show to assume the host will act a particular way for the viewers, he's in a death game where the host can do whatever he wants. You can try to hypothesize about archetypes of virtue and morality by playing hope chess such as by thinking "If the host wants to kill me, then he might have made it look like a Monty Hall Problem when it isn't, so maybe he placed the bullet in chamber 4 because someone who idiotically thinks it is the Monty Hall problem would assume chamber 6 has the bullet!" which is a valid psychological assumption that would imply it is the ***opposite*** to the Monty Hall Problem and results in a 100% probability of death by assuming it's the Monty Hall problem. But when you can start second guessing the psychology of the game host and make recursive "I think that you think that I think that you think" reasonings, the probability itself completely falls flat and has nothing to do with the Monty hall problem. There are no assumptions that can be made about the probability to skew it towards one side or the other side other than hopes about what the host would think and trying to counter what he thinks.

Possibility 2: The game is entirely about probability and there is no psychological game between you and the host. The host does not switch around the position of the bullet to try and simulate a Monty Hall problem or a reverse psychology problem, everything comes down to your luck based on the exact rules that were provided and an assumption that the host put the bullet randomly inside of the gun excluding what was revealed (chamber 5). In this case the probability of both chamber 4 OR 6 having the bullet is equally distributed. 50 percent.

Any assumption beyond these 2 possibilities would require you to force a rule onto the game that neither exists nor is there any valid reason behind assuming it does exist. To assume the rule exists because the host wants to do XYZ is to assume something about the psychology of the host, which falls back into possibility 1.

Since an infinite number of arbitrary rules stemming from the psychology of the host including the EXACT OPPOSITE to the Monty Hall Problem can be forced onto the game without it being said explicitly, the game is entirely separate from the Monty Hall Problem's probabilities (it all comes down to psychology, ethics, mindgames, etc.) and anyone who assumes it is 2/3 probability (Cai Zhiyuan and Cao Haichuan) is making a mathematical mistake.

The fact that they mentioned it would be 2/3 makes it clear they assumed it was a probabilistic game from the criminal's perspective rather than a mind game of trying to guess what kind of Monty Hall behaviour the host is following, which makes it 50-50. You can simulate it yourself using code.

The number of trial runs = 10000

Suppose a bullet is randomly distributed into 1 of the 6 chambers of the gun.

The host must reveal at the point of reaching chamber 4 that chamber 5 is empty, so if chamber 5 has a bullet, then it must be distributed to the other remaining chambers! If we assume the bullet could not have been in chamber 5 in the first place, it's still 50-50. The only way out is to assume the host picked the bullet position himself, in which case it becomes a mindgame rather than probability, OR to assume the host was trying to simulate a probability game when he revealed chamber 5 is empty in which case it becomes a recursive mindgame again. Here is if we assume it was pure probability with no mindgames involved:

    import random

    NUM_TRIALS = 10000

    def run_novel_simulation(trials=NUM_TRIALS):
        c4_count = 0
        c6_count = 0
        completed_trials = 0

        while completed_trials < trials:
            bullet = random.randint(1, 6)

            # Condition: The game must reach chamber 4.
            # If bullet in 1, 2, or 3, the game ended early so it has nothing to do with the Monty Hall Problem.
            if bullet in [1, 2, 3]:
                continue

            completed_trials += 1

            # Host reveals chamber 5 is empty.
            # If the bullet was in chamber 5, redistribute to 4 or 6:
            if bullet == 5:
                bullet = random.choice([4, 6])

            if bullet == 4:
                c4_count += 1
            elif bullet == 6:
                c6_count += 1

        return c4_count, c6_count

    if __name__ == "__main__":

        c4, c6 = run_novel_simulation(NUM_TRIALS)
        p_c4 = (c4 / NUM_TRIALS) * 100
        p_c6 = (c6 / NUM_TRIALS) * 100

        print(f"Chamber 4 (Current):  {c4} hits ({p_c4:.2f}%)")
        print(f"Chamber 6 (Switched): {c6} hits ({p_c6:.2f}%)")
