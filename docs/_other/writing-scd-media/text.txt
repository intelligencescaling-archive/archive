Writing an SCD media

# SCD Media

An SCD media classifies as a bunch of smart characters grouping together to form an analysis and provide a solution to a certain situation. The situation completely depends upon one's goal and the environment around them.

Let me just say here SCD media does not lack writing, it lacks how characters are written. For example A formulates a plan for B and somehow B evades it. How did he do that? Nah nobody knows he just that guy. That's an absolute bullshitting media.

SCD media also tries putting an extreme level of psychology so please do research before putting that.

# Story Decision

A story can be classified based on the environment or situation

|Number|Environment|Explanation|
|:-|:-|:-|
||
|1|Cat and Mouse|A situation where A is chasing B|
|2|Mindgame|A situation where 'A' is going against 'B' inside a certain game|
|3|Free Brawl|A situation where there are numerous characters involved|

A good SCD media utilizes all these types of situation. One thing to focus here, is that side stories, side arcs, all must dissolve into the main arc which is your main situation.

For example, if there is Cat and Mouse main situation, the Free Brawl or Mindgame can sub situation but it must not change the main focus here.

# Setting Situation Up

Setting up a situation is also for the good stakes, here are some pointers you can follow

* Draw the situation - Draw how the situation would work, create a map of where it's happening such as a crime scene
* Putting Elements - Putting Elements which could be classified into useful or useless.
* Strategise - You need to think from the perspective of antagonist to side characters to protagonist
* Use real world scenarios - Reading real scenarios is also a good way to create certain situations
* Make notes of concepts used - This is an important one

These could be followed to make a great situation.

# Character Writing

Most SCD media fails to write character why? because the character is already developed but to portray the character while showing intelligence etc etc. it becomes a bit difficult but guess what?

Main Character = Protagonist is a completely false statement. Main Character is the guy who we see the point of the story from, the Protagonist is the one through whom we see the story progressing. Example - Hughie is the MC of the Boys but Billy Butcher is the protagonist.

The character development can be gives to the Main Character and the Character insight which helps in Development to Protagonist

Overall if you don't wanna do that you could try these

1. Using Grief - Used in True Detective, Rust Cohle's past and present collides which gives him some form of character development
2. Using Driving Force - Such as Baku Madarame who uses the constant driving force of thrill
3. Using the Goal Oriented persona - Fang Yuan, who uses he Goal Oriented persona to dominate using his intelligence+mentality.
4. Using the physical limitations - This is a great one for a Fantasy story
5. Using external factors - Such as Light yagami driven by mainly the justice he wanted to serve by the external crime.

# Giving Importance

Just giving importance to MC or Protagonist won't work, give importance to side characters too, show a clash between ideologies, philosophy, intelligence etc. which creates a good story.

# "Top Tier"

Please don't think too much when you write characters, write simple strategies but don't write something carried by Narrative Statements. If you cannot think of complex plots then don't you don't have to. Write a story because you want to.

# Letting the MC win

It is the pinnacle of Bullshit. Letting the MC win every single time feel boring and repetitive, remember winning is good but Loss retrieval is even better.

# Personal Issues, Internal Struggles

This is the best type, showing these is absolute peak when writing SCD media.

# Love Interest

There is absolute no shame in showing it. Even more it adds a great element to the story.
