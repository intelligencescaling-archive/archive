Brief Overview of the Match Format:
Basically, this is standard mahjong, but with a few differences from the matches throughout the story, as this is commercial mahjong. Commercial mahjong has some different rules, as follows:
* Instead of allowing only one player to call Ron, the rules here allow multiple players to Ron on the same tile simultaneously.
* The match uses Aka Dora (Red Dora) tiles, which are red 5s. Here, we use three red 5s, replacing three regular black 5s (one red 5-Man, one red 5-Pin, and one red 5-Sou). Each red 5 counts as one Dora.
